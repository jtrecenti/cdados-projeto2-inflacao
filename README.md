# Projeto 2: descontando a inflação com o `python-bcb`

Material complementar do Projeto 2 de Ciência dos Dados (Insper, 2026.2).

O notebook [`Projeto2_Inflacao_IPCA.ipynb`](Projeto2_Inflacao_IPCA.ipynb) mostra como baixar o
IPCA do Banco Central com o pacote [`python-bcb`](https://wilsonfreitas.github.io/python-bcb/),
calcular o fator de correção de 2019 para 2025 (cerca de 1,40) e levar o VM2 de 2019 a reais
de 2025.
